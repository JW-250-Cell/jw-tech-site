JW TECH — SITE VITRINE POUR ARCAHAIE, HAÏTI

Contenu: index.html, styles.css, README.txt.

À faire avant publication:
- Vérifier le nom commercial JW Tech.
- Vérifier jwtech.ht auprès de NIC.ht : https://nic.ht/en/ (la disponibilité n'est pas confirmée).
- Vérifier l'adresse e-mail de contact.
- Configurer le bouton WhatsApp dans index.html avec un lien de type https://wa.me/NUMERO_INTERNATIONAL (numéro sans +, espaces ni tirets). Le bouton actuel est un emplacement et ne fonctionne pas encore.
- Les catégories sont indicatives: ne pas afficher de prix/stock avant confirmation d'un fournisseur.
- JW Tech est présenté comme indépendant, pas comme revendeur Apple agréé.
- Ajouter conditions de commande, paiement, livraison partout en Haïti, retours et confidentialité avant de vendre.

PUBLICATION GRATUITE:
1. Créer un compte https://github.com/
2. Créer un dépôt public jw-tech-site.
3. Ajouter index.html et styles.css à la racine.
4. Aller dans Settings > Pages.
5. Choisir Deploy from a branch, branche main, dossier /(root), puis Save.
6. Ouvrir l'URL fournie dans Settings > Pages.

DOMAINE:
Vérifier jwtech.ht via https://nic.ht/en/. Si acheté, ajouter d'abord le domaine dans Settings > Pages puis configurer les DNS selon:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
La propagation DNS peut prendre jusqu'à 24 heures.

GOOGLE:
Après publication, aller sur https://search.google.com/search-console/about, ajouter/vérifier le site et demander l'indexation de la page d'accueil. Cela ne garantit pas un classement ni une indexation immédiate.

Le site est un catalogue statique, sans panier, stock dynamique ni paiement en ligne.
